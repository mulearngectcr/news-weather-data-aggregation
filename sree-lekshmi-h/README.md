# Daily Brief

Daily Brief is a desktop application built with Python and Tkinter that provides users with the latest news on a selected topic along with real-time weather information for a chosen city. The application integrates NewsAPI and WeatherAPI to display news headlines and weather conditions in a user-friendly graphical interface.

## Features

- Graphical User Interface (GUI) using Tkinter
- Search news articles by topic
- Display top 5 news headlines
- Show article source and description
- Fetch real-time weather information
- Display temperature, weather condition, and humidity
- Weather condition emojis for better visualization
- Secure API key management using `.env` files
- Error handling for invalid API responses

## Technologies Used

- Python
- Tkinter
- Requests
- Python-Dotenv
- NewsAPI
- WeatherAPI
